GDLWebcamp — Event Management Platform

A full-stack web application for managing a developer conference, built with HTML5, CSS3, JavaScript, Ajax, PHP, and MySQL. The platform allows users to explore conferences and workshops, register for an account, purchase tickets, and customize their event experience, while administrators can manage speakers, events, attendees, and registrations.



Features

User Authentication: Account registration, login, email verification, and form validation.

Event Management: Create, edit, and delete conferences and workshops.

Speaker Management: Manage speaker profiles, biographies, areas of expertise, and social media links.

Event Scheduling: Organize events by category, day, and time while preventing scheduling conflicts.

Ticket Registration: Choose between free, virtual, and in-person attendance plans.

Online Payments: Integrate PayPal for paid ticket purchases.

Workshop and Conference Selection: Allow attendees to select up to five eligible events, subject to availability.

Capacity Management: Track available seats and prevent registrations when an event is sold out.

Gift Selection: Allow attendees to choose event merchandise during registration.

Digital Tickets: Generate personalized tickets with unique registration codes.

Admin Dashboard: Manage speakers, events, attendees, registrations, and revenue.

Pagination: Display records efficiently across multiple pages.

Interactive UI: Responsive layouts, animations, event sliders, and dynamic form elements.

Database Integration: Store and retrieve users, events, speakers, registrations, and payment information.



Tech Stack

Frontend: HTML5, CSS3, JavaScript

Asynchronous Requests: Ajax

Backend: PHP

Database: MySQL

Payment Processing: PayPal

Email Verification: Email-based account confirmation
